# Chrome 文本替换插件

一个简单的Chrome扩展程序，可以在网页上自动替换指定的字符串。

## 功能特点

- ✅ 自动检测并替换网页上的指定文本
- ✅ 支持多个替换规则
- ✅ 实时配置，无需刷新页面
- ✅ 可以随时启用/禁用替换功能
- ✅ 支持动态加载的内容（使用MutationObserver）

## 安装方法

1. 打开Chrome浏览器，进入扩展程序管理页面：
   - 在地址栏输入 `chrome://extensions/`
   - 或者点击右上角三点菜单 → 更多工具 → 扩展程序

2. 启用"开发者模式"（右上角开关）

3. 点击"加载已解压的扩展程序"

4. 选择本项目的文件夹

5. 插件安装完成！

## 使用方法

### 方式一：在配置文件中直接配置（推荐）

1. 编辑项目根目录下的 `config.csv` 文件
2. 使用CSV格式（两列）添加替换规则，格式如下：
   ```csv
   原文本,替换后的文本
   要查找的文本,替换后的文本
   另一个文本,另一个替换文本
   chen.yu,新的名字
   ```
   - 第一行是标题行（必须保留）
   - 第一列是"原文本"（要查找的文字）
   - 第二列是"替换后的文本"（替换成的文字）
   - 如果文本中包含逗号，需要用双引号括起来，例如：`"包含,逗号的文本","替换文本"`
3. 保存文件后，重新加载扩展程序（在 `chrome://extensions/` 页面点击刷新按钮）
4. 配置文件中的规则会显示为灰色背景（只读），表示来自配置文件

### 方式二：在插件界面中配置

1. 点击浏览器工具栏中的插件图标

2. 在弹出窗口中：
   - 使用"启用替换"开关启用/禁用替换功能
   - 使用"使用配置文件规则"开关控制是否使用 `config.csv` 中的默认规则
   - 点击"添加替换规则"按钮添加新的替换规则
   - 在"原文本"输入框中输入要查找的文本
   - 在"替换为"输入框中输入要替换成的文本
   - 点击"删除"按钮可以删除不需要的规则（配置文件中的规则不能删除）

3. 配置会自动保存，并在当前页面立即生效

**注意**：配置文件中的规则和界面中添加的规则会合并使用，配置文件中的规则会优先显示。

## 文件说明

- `manifest.json` - 扩展程序配置文件
- `config.csv` - **替换规则配置文件**（CSV格式，两列），可以在这里直接配置默认的替换规则
- `content.js` - 内容脚本，负责在网页中执行文本替换
- `popup.html` - 弹出窗口的HTML界面
- `popup.js` - 弹出窗口的JavaScript逻辑
- `icon16.png`, `icon48.png`, `icon128.png` - 扩展程序图标（需要自行添加）

## 注意事项

- **配置文件规则**：`config.csv` 中的规则是只读的，不能通过界面修改或删除，需要直接编辑文件
- **CSV格式说明**：
  - 第一行必须是标题行：`原文本,替换后的文本`
  - 每行一个替换规则，用逗号分隔
  - 如果文本中包含逗号，需要用双引号括起来
  - 空行会被自动忽略
- **用户自定义规则**：在界面中添加的规则会保存到Chrome存储中，会同步到Chrome账户，可以在不同设备间同步
- **规则合并**：配置文件中的规则和用户自定义规则会合并使用，配置文件规则优先显示
- 插件会在所有网页上运行，请谨慎配置替换规则
- 修改 `config.csv` 后需要重新加载扩展程序才能生效
- 某些动态加载的内容可能需要刷新页面才能生效

## 图标文件

由于无法自动生成图标文件，你需要：
1. 准备三个PNG图标文件：16x16、48x48、128x128像素
2. 将它们命名为 `icon16.png`、`icon48.png`、`icon128.png`
3. 放在项目根目录下

或者你可以暂时使用占位图标，插件功能不受影响。

## 开发说明

这是一个使用Manifest V3的Chrome扩展程序，主要技术点：
- Content Scripts用于在网页中执行脚本
- Chrome Storage API用于保存配置
- MutationObserver用于监听DOM变化
- Popup界面用于用户配置
